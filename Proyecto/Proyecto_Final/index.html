Descripción del Proyecto

Este geoportal permite consultar, visualizar y explorar las mediciones de contaminantes atmosféricos registradas por la Red Automática de Monitoreo Atmosférico de la Ciudad de México.

Este geoportal integra diversas tecnologías de código abierto para el despliegue y análisis de datos espaciales. Sus principales características incluyen:

  • Consumo de servicios WMS y WFS vía GeoServer.
  • Búsqueda avanzada conectada a PostgreSQL vía PHP.
  • Geoprocesamiento dinámico usando Python y PostGIS.
  • Visualización de datos estadísticos interactivos.
