Descripcion del Proyecto

Este geoportal integra diversas tecnologias de codigo abierto para el despliegue y anàlisis de datos espaciales. Sus principales caracteristicas incluyen:

  • Consumo de servicios WMS y WFS via GeoServer.
  • Busqueda avanzada conectada a PostgreSQL via PHP.
  • Geoprocesamiento dinamico (WPS) usando Python y PostGIS.
  • Visualizaciòn de datos estadisticos interactivos.

Capas Disponibles

Interactua con el mapa para ver datos de contaminacion atmosferica: gase como CO, NO, NO2, SO y material particulado (PM) dentro de la demarcaciòn de la CDMX.
