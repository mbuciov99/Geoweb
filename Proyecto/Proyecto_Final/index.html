Descripcion del Proyecto

Este geoportal permite consultar, visualizar y explorar las mediciones de contaminantes atmosféricos registradas por la Red Automática de Monitoreo Atmosférico de la Ciudad de México.

Mediante un formulario, el usuario puede seleccionar una estación y un contaminante de interés. La solicitud se conecta con una base de datos PostgreSQL/PostGIS a través de PHP y presenta los resultados en una tabla, una gráfica temporal y un mapa interactivo desarrollado con Leaflet.

Esta versión del Geoportal Analítico Multipropósito integra diversas tecnologias de codigo abierto para el despliegue y anàlisis de datos espaciales. Sus principales caracteristicas incluyen:

  • Consumo de servicios WMS y WFS via GeoServer.
  • Busqueda avanzada conectada a PostgreSQL via PHP.
  • Geoprocesamiento dinamico (WPS) usando Python y PostGIS.
  • Visualizaciòn de datos estadisticos interactivos.

Interactua con el mapa para ver datos de contaminacion atmosferica: gase como CO, NO, NO2, SO y material particulado (PM) dentro de la demarcaciòn de la CDMX.
